# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We want participation in this project to be a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, colour, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and kind, including when you disagree.
- Give and accept constructive feedback gracefully.
- Take responsibility for mistakes, apologise to anyone affected, and learn from them.
- Focus on what is best for the community.

## Unacceptable behaviour

- Sexualised language or imagery, and unwelcome sexual attention.
- Trolling, insulting or derogatory comments, and personal or political attacks.
- Public or private harassment.
- Publishing other people's private information without their explicit permission. Family data is personal: never post real people's details in issues.
- Other conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This code applies in all project spaces, including issues, pull requests and discussions, and when someone officially represents the project elsewhere.

## Reporting

Report incidents privately to the maintainer, [@chandanshakya](https://github.com/chandanshakya), through a GitHub private vulnerability report on this repository (Security → Report a vulnerability) and mark it as a conduct report. Reports are reviewed promptly and kept confidential.

## Enforcement

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that do not follow this code. Responses range from a private warning, to a temporary ban, to a permanent ban, depending on how serious the behaviour was and whether it was repeated.
